01The problem

When an agent dies, the next one starts from zero.

Real conversations run for weeks. Agents don’t. A replacement agent inherits an inbox, not an understanding. It doesn’t know that:

  1. aThe delivery date changed.delivery.schedule · superseded
  2. bThe supplier still owes us a revised quote.open loop · supplier
  3. cFinance already approved the budget.answered · do not re-ask

Rereading the whole thread works until it doesn’t: it’s slow, expensive, and the model still misses the correction on page nine.

02Mechanism

Continuity remembers where things stand.

Every inbound email becomes evidence. A resolver turns evidence into state: current terms, open loops, checks, and who acts next. Agents read the state, not the transcript.
